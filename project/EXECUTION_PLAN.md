# Execution Plan (v1)

## 목표
현재 React 프론트를 실사용에 가까운 기능으로 확장한다.

## 우선순위
1. 검색/정렬/페이지네이션
2. 회원가입
3. 댓글 작성
4. 좋아요/북마크(프론트 우선)

## 작업 항목

### 1) 검색/정렬/페이지네이션
- [x] `PostsPage`에 검색 입력(제목/내용), 정렬(최신/제목순), 페이지네이션 UI 추가
- [x] 백엔드 파라미터가 제한적일 수 있어 클라이언트 필터/정렬 처리

### 2) 회원가입
- [x] `SignupPage` 신규 추가
- [x] `POST /api/users` 연동
- [x] 내비게이션에 가입 링크 추가

### 3) 댓글 작성
- [x] `PostDetailPage`에 댓글 입력 폼 추가
- [x] `POST /api/posts/{postId}/comments` 연동
- [x] 등록 후 목록 재조회

### 4) 좋아요/북마크
- [x] 백엔드 엔드포인트 부재 대비 로컬스토리지 기반 구현
- [x] 게시글 상세에서 토글 UI 제공

## 참고
- 좋아요/북마크는 현재 프론트 저장 방식(localStorage)이며,
  백엔드 API가 준비되면 `api.js`에서 교체 가능.
